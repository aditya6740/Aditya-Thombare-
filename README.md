## 📥 Installation

### Quick Start

1. **Clone the repository:**
```bash
git clone https://github.com/aditya6740/Aditya-Thombare-.git
cd Aditya-Thombare-
```

2. **Add your assets:**
```bash
# Add your profile photo
# Name it: profile.jpg
# Recommended: 400x400px, circular crop

# Add your resume
# Name it: resume.pdf
```

3. **Open locally:**
```bash
# Using Python (macOS/Linux)
python -m http.server 8000

# Or open index.html directly in your browser
```

4. **View in browser:**
```
http://localhost:8000
```

## 🎨 Customization

### Edit Hero Section

Open `index.html` and update:

```html
<h1 class="hero-title">Your Name</h1>
<h2 class="hero-subtitle">Your Title | Your Specialty</h2>
<p class="hero-desc">Your tagline here</p>
```

### Modify Expertise Cards

In `index.html`, update expertise section:

```html
<div class="expertise-card">
    <i class="fas fa-your-icon"></i>
    <h3>Your Skill</h3>
    <p>Description of your skill</p>
</div>
```

Browse [Font Awesome Icons](https://fontawesome.com/icons) for more icons.

### Update Contact Information

```html
<a href="mailto:your-email@example.com">your-email@example.com</a>
<a href="https://linkedin.com/in/your-profile" target="_blank">LinkedIn</a>
```

### Customize Chart Data

In `script.js`:

```javascript
labels: [
    'Skill 1',
    'Skill 2',
    'Skill 3',
    // Add your skills
],
data: [90, 85, 80, ...], // 0-100 scale
```

### Color Scheme

Update CSS variables in `style.css`:

```css
:root {
    --primary-color: #0066cc;      /* Main blue */
    --secondary-color: #00a8e8;    /* Light blue */
    --accent-color: #ff6b35;       /* Orange */
    --dark-bg: #0f1419;            /* Dark background */
}
```

## 🚀 Deployment

### Deploy to GitHub Pages (FREE)

1. **Ensure your repo is public:**
   - Go to GitHub repository settings
   - Scroll to "Visibility"
   - Select "Public"

2. **Enable GitHub Pages:**
   - Settings → Pages
   - Under "Source", select `main` branch
   - Save

3. **Access your portfolio:**
```
https://aditya6740.github.io/Aditya-Thombare-/
```

### Deploy to Other Platforms

#### Netlify (Recommended)
```bash
# Install Netlify CLI
npm install -g netlify-cli

# Deploy
netlify deploy --prod --dir .
```

#### Vercel
```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel --prod
```

#### Traditional Hosting
- Upload files via FTP to your hosting provider
- Ensure `index.html` is in the root directory
